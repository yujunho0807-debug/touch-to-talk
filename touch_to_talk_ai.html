👁️ 시선 추적 카메라 보안 안내

현재 파일을 직접 더블클릭(file://)으로 열어 브라우저 보안 정책상 웹캠 접근이 차단되었습니다.
로컬 서버(http://localhost:8000) 또는 HTTPS 사이트로 열면 웹캠과 시선 추적이 즉시 작동합니다.

1) 파일이 저장된 폴더 주소창에 cmd 입력 후 아래 명령어 실행:
python -m http.server 8000
2) 크롬 주소창에 http://localhost:8000 입력 후 접속하여 시선 추적 OFF 버튼 클릭

🎯 시선 추적 5점 보정

화면 모서리와 중앙에 나타나는 빨간 점 5개를 눈으로 바라보면서 각각 2번씩 클릭(또는 터치)해 주세요.
보정이 끝나면 원하는 버튼을 1.5초간 바라보기만 해도 원형 게이지가 차오르며 자동 선택됩니다.
